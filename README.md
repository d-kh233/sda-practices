# Backup App — резервное копирование папок

Настольное приложение на Java (Swing) для резервного копирования папок в Windows 10/11.
Создаёт полные и инкрементальные копии в ZIP-архивах и восстанавливает папку на момент любой копии.

## Возможности

- Выбор исходной папки и папки-хранилища (любая папка, флешка, сетевой путь `\\server\share`).
  Хранилище нельзя выбрать внутри исходной папки — это защита от рекурсии.
- **Полная копия** — все файлы папки в ZIP + JSON-манифест рядом (список файлов, размеры, даты, SHA-256).
- **Инкрементальная копия** — только новые и изменённые файлы с момента последней копии,
  в манифест записывается список удалённых файлов (`deletedFiles`).
- Два способа найти изменённые файлы:
  - быстрый — по дате изменения и размеру;
  - надёжный — по хэшу SHA-256 содержимого.
- Перед копированием проверяется свободное место; кнопка «Оценить время и место» показывает
  примерное время для обоих режимов.
- Архив сначала пишется во временный файл `.tmp` и переименовывается в `.zip` только после
  успешного завершения — при ошибке или нехватке места битых копий не остаётся.
- Таблица всех копий, восстановление выбранной копии в любую папку (собирается цепочка
  «полная копия → инкременты»), удаление копии с предупреждением о зависимых инкрементах.
- Необязательный таймер: автоматическая копия каждые N минут, пока программа открыта.

## Требования

- JDK 17 или новее (проверить: `java -version`)
- Apache Maven 3.8+ (проверить: `mvn -version`)

## Сборка

```bash
mvn clean package
```

Maven скачает библиотеки, скомпилирует код, запустит тесты и соберёт исполняемый fat-JAR:
`target/backup-app-1.0.jar` (код приложения и все библиотеки в одном файле).

Собрать без запуска тестов: `mvn clean package -DskipTests`

## Запуск

```bash
java -jar target/backup-app-1.0.jar
```

В Windows JAR также можно запустить двойным щелчком, если Java установлена.

### Пример работы

1. «Исходная папка» → `C:\Users\Anna\Documents`, «Папка-хранилище» → `E:\Backups`.
2. «Оценить время и место» — программа покажет объём папки, свободное место и примерное время.
3. «Создать полную копию» — в `E:\Backups` появятся
   `backup_20261119_223015_123_full.zip` и `backup_20261119_223015_123_full.json`.
4. Изменить файлы в папке → «Создать инкрементальную копию» → появится `..._incr.zip` и `..._incr.json`.
5. Выбрать копию в таблице → «Восстановить выбранную копию…» → указать пустую папку.

## Структура проекта

```
backup-app/
├── pom.xml                         — файл сборки Maven
├── README.md
└── src/
    ├── main/java/com/backupapp/
    │   ├── Main.java               — точка входа
    │   ├── model/                  — данные: задание, манифест, сведения о файле
    │   ├── strategy/               — паттерн «Стратегия»: способы найти изменения
    │   ├── service/                — логика: ZIP, манифесты, копирование, восстановление, фасад
    │   └── ui/                     — окно Swing
    └── test/java/com/backupapp/    — юнит-тесты JUnit 5
```

## Паттерны проектирования

| Категория      | Паттерн   | Классы                                                                              |
|----------------|-----------|--------------------------------------------------------------------------------------|
| Порождающий    | Строитель | `BackupJobBuilder` → `BackupJob`                                                     |
| Структурный    | Фасад     | `BackupFacade` (скрывает `BackupService`, `RestoreService`, `BackupCatalog`, `ZipArchiver`, `FolderScanner`) |
| Поведенческий  | Стратегия | `ChangeDetectionStrategy`, `FastMetadataStrategy`, `ReliableHashStrategy`            |

## Сторонние библиотеки

| Библиотека | Версия | Зачем |
|------------|--------|-------|
| [FlatLaf](https://www.formdev.com/flatlaf/) (`com.formdev:flatlaf`) | 3.6.1 | современный внешний вид Swing |
| [Gson](https://github.com/google/gson) (`com.google.code.gson:gson`) | 2.13.1 | чтение и запись JSON-манифестов |
| [JUnit 5](https://junit.org/junit5/) (`org.junit.jupiter:junit-jupiter`) | 5.11.4 | юнит-тесты (только при сборке) |

Плагины Maven: `maven-compiler-plugin`, `maven-surefire-plugin`, `maven-shade-plugin` (сборка fat-JAR).

Архивы ZIP создаются стандартным пакетом `java.util.zip`, хэши — `java.security.MessageDigest`.

## Что не входит в проект

Шифрование паролем, автоудаление старых копий, восстановление отдельных файлов,
исключения файлов, журнал в файл, CLI и веб-интерфейс.
